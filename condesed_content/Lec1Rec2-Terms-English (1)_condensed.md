# Lec1Rec2: Cybersecurity Terms, Risk, Threats, Vulnerabilities, and Exploits

## Key Terms - risk, threat, vulnerability, exploit; use correctly in reports/policies.

## Asset Inventory - list hardware, software, applications, customer data.

## Valuable Assets - IP, trade secrets, payment data, PII.

## PII - personally identifiable information such as name or driver's license data.

## Threat Identification - depends on knowing protected assets.

## Known Threat - recognized signature/characteristics; detectable.

## Unknown Threat - new/zero-day; not yet detected by AV.

## APT - long-term effort to gather information, compromise systems, and cause severe damage.

## Vulnerability - weakness allowing a threat source to compromise security.

## Vulnerability Examples - outdated firmware, unlocked computer, poor software, careless logout/password habits.

## Exploit - using a vulnerability to compromise/harm an asset.

## Risk - probability a threat exploits a vulnerability times impact.

## Risk Formula - `Risk = Probability x Impact`.

## Risk Example - saved plaintext password + hacker + financial officer access = very high risk.

## Example Mapping - hacker threat agent; insecure password storage vulnerability; using password exploit; financial system asset.

## Safeguards - security officer identifies protections for assets against threats.

## MAO Model - motivation, ability, opportunity.

## MAO Mapping - motivation = threat actors; ability = exploits; opportunity = vulnerabilities.

## Cybercrime Condition - motivation + ability + opportunity likely produces attack behavior.

# Lecture 7 Recording 1: TCP/IP Model

## Network Model - layered framework for network communication tasks.

## Layer Benefits - specific functions, logical processing, easier fault location.

## OSI Model - seven-layer Open Systems Interconnection model.

## TCP/IP Model - practical protocol-oriented model, often four or five layers.

## OSI vs TCP/IP - OSI separates more functions; TCP/IP groups functions for practical protocols.

## Course Model - TCP/IP.

## Segmentation - divide large data into smaller pieces.

## Encapsulation - add source, destination, protocol, and handling information as data moves through layers.

## Package Analogy - split large item, label packages, deliver through transport links.

## Multiplexing - combine multiple data streams into shared transport capacity.

## Container Analogy - many packages share containers for efficient delivery.

## Delivery - protocols read destination info and coordinate across layers.

## TCP/IP Security Problem - designed for connectivity/reliability, not security.

## Historical Weakness - built in 1970s before modern Internet abuse was expected.

## Identity Weakness - IP addresses are not strongly tied to real identities.

## Attack Tool Availability - free tools and Internet scale increase risk.

## Open Systems Security Architecture - later framework for security services/mechanisms.

## Course Security Focus - issues in each TCP/IP layer and secure protocol design.

## Security Attributes - five security attributes considered across layers.

# Cybersecurity Course Introduction and Motivation

## Course Approach - practice/application-based; understand theory behind workshop tasks.

## Exam Preparation - complete workshops, know why answers are correct, connect practice to theory.

## Course Scope - broad domains: network security, cryptography, authentication/access control, policy.

## Materials - slides, learning activities, self-review quizzes, course resources.

## References - CISSP All-in-One, crypto books, SEED Labs.

## Software Security Scope - mostly excluded; small provided code only for crypto understanding.

## Week 1 Foundation - CIA model; risk, threat, vulnerability, exploit.

## Cybersecurity Importance - protects software, data, devices, infrastructure, organizations, daily life.

## Vulnerability - weakness in software/system/process; assigned IDs when identified.

## Vulnerability Causes - buffer overflow, SQL injection, XSS, CSRF.

## Data Breaches - expose personal data, source code, records; affect companies, governments, banks, telecoms.

## Physical Cybersecurity Impact - compromised control systems can affect nuclear facilities, cars, pacemakers, infrastructure.

## Critical Infrastructure - electricity, water, rail, and control systems can be attacked.

## Career Demand - workforce shortage; roles include security architect, engineer, secure development.

## Career Pathways - feeder roles, entry-level, mid-level, advanced roles.

## Certifications - CISSP, CASP-style, CEH, Cisco security; require knowledge and experience.

## Course Dimensions - people, technology, policy; technology alone is insufficient.

## Course Topics - ransomware, RSA, packet sniffing, secure protocols, Essential Eight policy.

## MAO Framework - cybercrime needs motivation, ability, and opportunity.

## Motivation - money, data, control, other benefits.

## Ability - attackers can buy tools/ransomware with limited skill, often using crypto payments.

## Opportunity - vulnerable targets: phishing clicks, unpatched systems, weak awareness.

## Defender Asymmetry - defenders must close every hole; attackers need one.

## Attacker Understanding - know attacker identity, motives, and entry methods to defend.

## Hacker Types - black hat malicious; white hat ethical; gray hat mixed.

## Communication - use course site, lecture chat, and Teams.
